
# SEA — Software Environments for Agents

**Open-source infrastructure for creating reproducible and verified environments for AI agents.**

SEA aims to help developers turn Docker-based software repositories into reproducible tasks that AI agents can solve and be evaluated on.

## The problem

Creating reliable environments for AI agents often involves significant manual work:

- Setting up reproducible environments.
- Defining realistic tasks.
- Writing reliable state-based verifiers.
- Testing incorrect solutions and potential reward hacking.
- Ensuring reproducibility.

## Our vision

SEA aims to automate parts of this process while helping developers validate the reliability of their environments and verifiers.

We want to complement existing tools such as [Harbor](https://github.com/laude-institute/harbor) and [OpenEnv](https://github.com/meta-pytorch/OpenEnv), not replace them.

## Current status

**Early-stage project — November 2026.**

SEA is currently in the problem-validation and research phase.

We are investigating:
- How developers currently create agent environments.
- What remains difficult with existing tools.
- Whether automated task and verifier generation can meaningfully reduce development time.

No production-ready functionality is available yet.
